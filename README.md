# Radar SONAMI

Sitio estático del monitor regulatorio y reputacional de SONAMI. `index.html` se actualiza automáticamente desde la tarea programada del radar (reemplaza el bloque `<script type="application/json" id="radar-data">`). No editar ese bloque a mano.

- Publicación: GitHub Pages (rama `main`, carpeta raíz).
- Dominio: `radar.sonami.cl` (registro CNAME hacia `<cuenta>.github.io`).
- Historial: cada actualización queda como un commit; cualquier versión anterior se puede ver o restaurar desde la pestaña *History*.
