    Cada mañana, antes de las 09:00, se envía un resumen con los hallazgos críticos a estas direcciones, más una alerta si aparece algo crítico durante el día. No necesitan cuenta de Claude.

    Cómo funciona. Una tarea automática revisa cada hora las fuentes urgentes (alertas SENAPRED, sismos, prensa sobre SONAMI, hechos esenciales, tabla del Senado), hace la barrida completa temprano para tener todo listo a las 09:00 y una segunda revisión de las fuentes importantes lista a las 14:00. Los precios del cobre y el litio son los oficiales de Cochilco: a las 09:00 se muestra el cierre del día hábil anterior y en la tarde el precio del día, apenas Cochilco lo publica. Solo registra lo nuevo; las alertas que terminan quedan marcadas como cerradas. Criticidad: Crítica = afecta directamente a SONAMI o a un socio, o exige reacción el mismo día. Alta = normativa, causa o sanción del sector con impacto gremial. Media = seguimiento sectorial. Info = contexto. Cobertura: el Poder Judicial se cubre vía los tres Tribunales Ambientales y el TDLC; la tramitación de reglamentos en Contraloría, por prensa especializada.
